## 1. Claude Code releases 2.1.288 → 2.1.295

The summary only covered 2.1.288 and 2.1.289. **[!]** Seven releases have shipped since 10/3, and most of them change something about mods. Only the lines that touch mods are listed. **[V]**

### New API surface

| Version | Addition |
|---|---|
| 2.1.288 | `$.ui.selection()` returns the text last selected in fullscreen mode, plus the transcript row if the selection sits within one row |
| 2.1.289 | `agent.spawn` fires for teammates; one agent id across plugin hook events; idle and waiting states in `$.agent.list()` |
| 2.1.290 | `turn.step` result gains `serverToolUses` (tool calls the API ran itself, e.g. the advisor) |

| 2.1.292 | New event `prompt.autocomplete`: add rows to the prompt box's autocomplete list |
| 2.1.292 | `$.model.complete` prompt caching: `prompt`/`system` take blocks; `cache: true` caches up to that block |

### Fixes worth knowing

- **2.1.289: installed mods didn't load in the first session after an upgrade.** Fixed. If a mod seemed to do nothing right after updating, this was probably the cause. **[V]**
- **2.1.295: a hook was handed a deeply nested tool input that had been cut short, with no error, so a guard could pass content it never saw.** This matters for any `tool.call` guard, `blast-guard` included. **[V]**
- 2.1.289: a deny/ask rule on part of a compound shell command now holds over a user-installed mod's approval on managed machines. **[V]**
- 2.1.289: a launch freeze when a plugin drew a `Box` with an unknown border style; sessions ending when an on-screen handler threw asynchronously; panes drawing nothing for some link forms. **[V]**
- 2.1.290: a hook with a `.catch` could be unloaded and its `.catch` skipped when it kept the hooks worker busy. **[V]**
- 2.1.293: a mod's `classic.*` hooks were skipped while the hooks worker restarted. `ledger` relies on `classic.SessionStart`, so this could have caused the reload-after-`/clear` bug to come back intermittently. **[V]** (connection to `ledger` is **[I]**)
- 2.1.288: a mod's `tool.call` hook broke Bash and file searches in subagents that run in a worktree. **[V]**

## 4. Follow-up, done 2026-10-08 on 2.1.295

**Samples.** All five pass `claude plugin validate` and `claude plugin test` (9 tests) under 2.1.295, and all type-check with `tsc` 5.9.3 against the 2.1.295 declarations. The `.typecheck/` configs now point at `research/bundled-2.1.295/`.
The new validate output lists every gating hook in our samples as `gating hook without .catch` (tool-counter, house-rules, blast-guard, turn-receipt and ledger all have at least one). The 2.1.295 reference calls this "a fact, never a warning": without a `.catch`, a guard that throws or overruns is skipped. It suggests `.catch(($, e, next) => next.called ? next(e) : { deny: 'why' })` for real guards. `.catch` already existed in 2.1.287 and Anatomy already covers it, so nothing there was wrong. `blast-guard` stays a teaching sample without one.

**Bundled reference.** `research/bundled-2.1.295/` now holds `reference.md` (215 lines, was 144), the five examples and `types/claude-code.d.ts` (21,463 lines, was 20,114). How to get it: load the `plugin-authoring` skill. The engine writes the bundle to `/private/tmp/claude-<uid>/bundled-skills/<version>/<hash>/plugin-authoring/`. A headless `claude -p --plugin-dir` run does **not** write `.claude-plugin/types/` into the mod folder.

**Event count.** Counted from `EngineEventOf` in the declarations (the same method gives 43 for 2.1.287, matching the guides): **46 in 2.1.295.** New:
- `prompt.autocomplete`: adds rows to the prompt box's typeahead for the token at the cursor. It can change things; nothing waits on it.
- `prompt.mention`: fires once per path named after `@` in a prompt, before the engine reads it. It can add `context`, read another path, or `{ deny }`. **No `tool.call` is raised for that read**, so a `tool.call` guard never sees `@`-mentioned files; a secrets guard has to hook both. The doc's own remark: a guard here that fails is skipped and the file is read, so give it a `.catch`.
- `ui.fault`: watch only. Fires when a `Client` this plugin drew fails (module didn't load, drawing failed, code failed after drawing); the engine then redraws that site without it.

**API names.** Every `$.x`, `$.x.y` and `noun.verb` name in both guides still appears in the 2.1.295 declarations or reference. Nothing the guides teach was renamed or removed. (This checks names, not every claim's meaning.)

**Guides updated** (local files, not yet republished):
- Anatomy: Figure 3 adds `prompt.autocomplete`, `prompt.mention` (can stop) and `ui.fault` (watch only), and is 68 units taller to fit; checked in headless Chrome, no overlaps. Text now says 46 events and 2.1.295 declarations; the "can stop" caption adds `@`-mentioned files; the source-of-truth note points at `bundled-2.1.295/`.
